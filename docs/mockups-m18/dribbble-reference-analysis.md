## Common DNA (the owner's taste, distilled)

1. Warm cream / soft-tint grounds — never stark white, never dark cosmic.
2. **One black ink object anchors every pastel screen** (CTA pill, selected-day
   pill, docked nav). Pastels stay calm because one black shape holds the page.
3. A playful radial diagram as hero (the food-scanner flower ≈ our element
   compass, warmer).
4. Editorial mixed-style headline: italic-serif run inside a bold sans line.
5. Small tinted stat/category tiles with icons; dotted/dashed outlines as a
   recurring accent device.
6. Horizontal date strip, selected day = black pill.

## Round 5 — Trail (freestyle sibling, 2026-07-30)

Trail (first tab in today-three-treatments.html) is not a translation of the
picks but a new concept built on their DNA: the day as a route on a
topographic map, because the reading copy already speaks in terrain ("pothole
sign on the road", "a stretch worth taking slower", "the day runs crosswise").
What it keeps from the picks: one black anchor per screen (you-are-here pill,
signpost, nav), the italic-serif run inside a bold headline, dashed/dotted
accents, tinted signage tiles. What it changes: palette (olive topo-paper +
pine ink, map-legend element hues), type (Bricolage Grotesque display + Space
Mono map labels; Figtree stays for body), and the page architecture — the
clash is a marked crossing on a contour-map hero, the week is an elevation
profile, reading sections are waypoints on a dashed rail, and the agency line
is a directional trail sign. The orbit logo doubles as the compass rose.

**Round 5b — dynamic day palette (owner request, 2026-07-30):** the terrain
palette is keyed to the day pillar's element, deterministic per date. Five
terrains: Wood = olive forest (the original), Fire = blush canyon, Earth =
loess dune, Metal = porcelain granite, Water = nautical chart — each with a
matching night-hike dark theme. Only paper/ink/muted tokens shift; the element
data hues, the black anchor objects, and the green/amber signage colors stay
constant so color never changes meaning day to day. Zodiac-keyed palettes
(12) were considered and set aside — they blur into sameness, and the animal
already owns the day's identity as the silhouette on the map. The dashed
"DAY PALETTE · PREVIEW" capsule in the mockup is preview chrome only; the real
app shows exactly one palette per day.
