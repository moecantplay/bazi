# Paywall UI

Status: draft · Milestone: M22 · Ticket: 03

## Problem

No UI for premium features.

## Goal

Gated features explain themselves plainly and never dead-end.

## Requirements

- **R1.** Upsell copy follows VOICE.md: no fear, no "unlock your destiny", plain words about what the feature does.
  - Acceptance: voice tests over the copy.
- **R2.** Gated screens degrade gracefully: show what the feature is, one action to subscribe, a way back.
- **R3.** Free screens contain no upsell interruptions.

## Out of scope

Pricing page marketing.
